# Integration overview

deciwa comes to where people already work ({need}`DEC_INTEGRATIONS`). Every
integration shows the same [review UI](../product/ui.md) and talks to the
same CLI, so feedback given in one place shows up in all others.

| Integration | Where you review | Status |
|---|---|---|
| [Sphinx](sphinx/index.md) | the built docs in the browser – with Sphinx-Needs | available |
| [VS Code](vscode.md) | the editor and its docs preview | 0.3 |
| [Web script](web.md) | any website, with one line in the page | available |
| [Chrome](chrome.md) | any rendered page – docs or website | 0.4 |
| [Claude](claude.md) | a conversation with the AI; Claude asks at the element | usable now with the CLI; skills in 0.1, UI later |
| [monsterbrain](monsterbrain.md) | the rendered files and the change view of the danwos desktop app | planned |
| [Desktop app](desktop.md) | without a development environment | later |
